Tasks

Task management and status tracking

Get tasks with optional filtering

Retrieves all tasks, optionally filtered by status, group, or assignee

query Parameters
status
string
Enum: "pending" "done" "late"
Example: status=pending

Filter tasks by status (pending, done, late)

groupId
string
Example: groupId=g1

Filter tasks by group ID

assignee
string
Example: assignee=anna

Filter tasks by assignee (member ID)

Responses

Development server

http://localhost:5000/api/tasks

Production server

https://api.studysync.example.com/api/tasks

Response samples

  • 500
